Tài liệu EMS API Callback — LSS Logistics

1. Thông tin kết nối

Thông tinGiá trị
URLPOST https://emslss.ems.com.vn/api/lss/callback
Content-Typeapplication/json
Xác thựcHeader X-API-KEY: EMSLSS2026

2. Request

2.1 Headers

HeaderBắt buộcMô tả
X-API-KEY✔API key xác thực
Content-Type✔application/json

2.2 Body

TrườngKiểuBắt buộcMô tả
ems_codestring ✔ Mã EMS đơn hàng
statusstring ✔ Trạng thái callback (xem mục 3)
timedatetime — Thời gian xảy ra sự kiện.
Format: yyyy-MM-ddTHH:mm:ss (giờ Việt Nam).
Mặc định: thời gian server nhận request.
imagesstring[] ✔ (*) Danh sách URL ảnh. Bắt buộc với picked_up, delivered.
signature_imagestring ✔ (*) URL ảnh chữ ký người nhận. Bắt buộc với delivered.
notestring — Thông tin giao nhận.
reasonstring ✔ (*) Lý do thất bại. Bắt buộc với failed.

3. Danh sách trạng thái

Giá trị gửi lênÝ nghĩaTrường bắt buộc thêm
new_orderĐơn hàng mới tạo—
assigned_pickupĐã phân công lấy hàng—
picked_upĐã lấy hàng thành côngimages
in_transitĐang vận chuyển—
deliveredGiao hàng thành côngimages, signature_image, note
failedGiao hàng thất bạireason
cancelledĐã hủy đơn—
Các trạng thái không có trong danh sách trên vẫn được ghi nhận vào lịch sử nhưng không cập nhật trạng thái chính của đơn hàng.

4. Response

4.1 Thành công — HTTP 200

{
  "status": "success"
}

4.2 Lỗi — HTTP 400 / 404 / 500

{
  "status":  "error",
  "code":    "03",
  "message": "Trạng thái 'picked_up' bắt buộc phải có ảnh"
}

5. Bảng mã lỗi

CodeHTTPMô tả
01400Thiếu ems_code
02400Thiếu status
03400picked_up: thiếu images
04400delivered: thiếu images
05400delivered: thiếu signature_image
06400delivered: thiếu note
07400failed: thiếu reason
08404Không tìm thấy đơn hàng với ems_code đã cung cấp
99500Lỗi hệ thống
